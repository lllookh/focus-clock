# 专注时钟

一个简洁、跨平台的专注计时 PWA 应用，基于手绘稿开发。

## 功能

- **专注计时**：可设置 1–180 分钟专注时长，首页提供常用预设（15/25/45/60/90 分钟）。
- **圆形进度**：专注中显示灰色透明圆环进度，小球从 12 点位置顺时针转完一圈代表结束。
- **中途提示**：可在区间内随机响起提示音（如 5–7 分钟），支持自定义区间，也可关闭。
- **结束提示**：专注结束时播放悦耳提示音，提供 4 种音效风格，并支持上传自定义提示音。
- **无限暂停**：专注过程中可随时暂停/继续，无次数限制。
- **休息流程**：专注完成后主动进入休息设置页，自定义休息时长，休息结束播放海浪声，并浮现江湖体「共勉，加油」后返回首页。
- **数据统计**：统计今日、本周、累计专注次数与累计分钟数，提前结束也会计入次数。
- **记录管理**：可在设置中删除任意一次历史专注记录。
- **数据导入导出**：所有记录保存在本地，可导出为 JSON 备份或从 JSON 恢复。
- **GitHub 账号同步**：在设置中输入 GitHub Personal Access Token，即可通过 Gist 跨设备同步数据；不登录也可完整单机使用。
- **界面亮度**：可在设置中调节整体亮度。
- **PWA 安装**：支持添加到手机/电脑桌面，离线可用。

## 使用方式

1. 用浏览器打开 `index.html`（推荐通过本地服务器打开，以获得 Service Worker 和 PWA 支持）。
2. 点击「开始」进入专注。
3. 专注中可暂停、继续或结束。
4. 正常完成专注后，选择休息时长进入休息倒计时。
5. 点击设置图标可调整音效、亮度、时长、循环、数据、记录管理与账号同步。

## GitHub 同步说明

1. 登录 GitHub 后，进入 Settings → Developer settings → Personal access tokens → Tokens (classic)。
2. 生成一个 token，勾选 `gist` 权限。
3. 在「专注时钟」设置页粘贴 token 并登录。
4. 应用会自动创建/更新一个名为「专注时钟数据同步」的私有 Gist 用于同步。

## 本地预览

如果你有 Python：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080。
